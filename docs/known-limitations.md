# Known MVP Limitations

> **Status:** placeholder — to be completed before mainnet rollout.

Documented limitations will include:

- Single treasury address
- USDT TRC-20 only, `transfer` method only
- TRON Mainnet only
- Three fixed signers, 2-of-3 threshold
- No batch payments
- No on-chain permission management
- Manual Executor broadcast (no auto-broadcast by default)
- DB-backed queue (no Redis)

See project bible §1.3 for full out-of-scope list.
